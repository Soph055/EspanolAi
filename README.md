# EspañolAi 🇪🇸
> An AI-powered Spanish learning platform for real conversation practice, grammar correction, and vocabulary building.

---

## Features

- **Sentence Correction** — Write a Spanish sentence, get instant AI feedback with a clear explanation of what to fix and why
- **Vocabulary Tracker** — Save words you're learning, mark them as learned, and get AI-generated quizzes targeting your weak spots
- **Conversation Practice** — Chat with an AI in Spanish, get natural responses, and receive grammar feedback after each message
- **Document Practice** — Upload a Spanish text or article and get AI-generated practice questions from it
- **Progress History** — Review past corrections and conversation sessions to track improvement over time

---

## Tech Stack

**Frontend**
- React (Vite)
- CSS

**Backend**
- Node.js + Express.js
- MySQL
- Redis (caching AI responses)
- AWS S3 (document uploads)
- Zod (input validation)
- Winston + Morgan (logging)
- JWT (authentication via httpOnly cookies)
- bcrypt (password hashing)

**AI**
- OpenAI / Anthropic API
